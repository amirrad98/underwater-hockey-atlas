# UNBC TimberWhales brand assets

Copied unchanged from the UNBC TimberWhales brand kit v1.0 (Deep End colourway): outlined logos
(`logos/outlined/`), the field pattern and, in `../favicon.svg`, the kit's web favicon. Colour and
type tokens in `src/style.css` (`--tw-*`) come from the kit's `web/brand.css`.

Logo rules from the kit: keep proportions, leave the height of the U of UNBC clear on every side,
and below 140 px wide use the whale or profile picture alone.
