# Underwater Hockey Atlas + Wiki

A planned visual atlas of underwater hockey, connected to deep wiki articles and curated resource libraries. The site will include a UNBC Timber Whales profile with links to related places, teams, history, and resources.

## Planned scope

- Explore clubs, venues, regions, and competitions through a visual atlas.
- Follow links into wiki articles covering the sport, equipment, rules, skills, and history.
- Browse a resource library with clear attribution and links to original materials.
- Connect the UNBC Timber Whales profile to the wider atlas and wiki.

## Source provenance

Use public sources only. Record the original source URL, publisher or organization, retrieval date, and any reuse license or permission for factual content and media. Prefer primary sources, cite claims near the relevant content, and distinguish verified facts from gaps or conflicting reports. Do not import personal private notes or assume third-party media may be redistributed.

## Setup status

This private repository is initialized for a future cloud coding task. App implementation, dependency selection, content research, and deployment are separate work. No production secrets are required for this setup; a Node.js web toolchain is the intended starting point.
