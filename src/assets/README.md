# Visual assets

`timberwhales-logo.jpg` is the original UNBC Timberwhales artwork supplied by
the project owner for this revision. The image file is unchanged. The display
frame trims its blank white margins with CSS; the orca and lettering remain
visible at every reviewed size. It identifies the featured club, not the atlas
as an official club publication.

The three Open Sans WOFF files were encoded from the installed Open Sans font
distribution. Copyright, source, conversion notice, and the Apache 2.0 license
are retained in `fonts/LICENSE.txt`. The fonts are bundled with the application
so the hosted site and standalone review preview use the same typography without
third-party font requests.
